## About Me

I'm a B.Tech Computer Science student at Graphic Era Hill University with a strong interest in full-stack development, clean architecture, and building things that solve real problems.

I built this portfolio entirely from scratch — no templates, no page builders — because I wanted a site that actually reflects how I write code: organized, intentional, and easy to maintain. Every section, from the layout to the animations, was designed and built by hand.

Right now I'm focused on strengthening my Data Structures & Algorithms fundamentals while expanding into the MERN stack, and this portfolio grows alongside that — new projects, new sections, and continuous refinement.

<br />

## What This Site Includes

- **Responsive Design** — built mobile-first, polished across every screen size
- **Dark Theme UI** — a premium, distraction-free interface
- **Project Showcase** — real projects with live demos, source code, and details
- **Engineering Journey** — a timeline of how I got here and where I'm headed
- **Live LeetCode Stats** — my problem-solving progress, updated automatically
- **Highlights** — hackathon results and key milestones
- **Smooth Animations** — thoughtful, subtle motion — not decoration for its own sake
- **Contact Section** — simple, direct ways to reach out

## Running It Locally

```bash
git clone https://github.com/mitulupadhyay/mitulupadhyay.github.io.git
cd mitulupadhyay.github.io
npm install
npm run build
```

Then open `index.html` in your browser.
